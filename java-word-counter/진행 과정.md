## 진행 과정 및 시행착오
- 메뉴 입력 및 동작에 대해 구현 없는 메서드를 만들어 동작을 분류함
- TXT, CSV, TSV, HTML 등의 문서를 읽을 때 TextReader라는 인터페이스로 묶도록 설계 -> 공통된 읽기 동작이 있으므로
- 입력 경로를 기반으로 파일들을 읽고 분석하는 Analyzer 클래스 정의
- 파일 처리를 어떻게 할 것인가 고민
  - 경로 문제 -> 경로 문자열 자체가 잘못된 경우, 해당 경로를 찾을 수 없는 경우
  - 파일 및 디렉터리 문제 -> 둘을 어떻게 구분할 것이며 디렉터리 내의 파일을 어떻게 나열할 것인지
  - 각 단계 실패 시 어떻게 동작할 것인지 혹은 어떻게 예외를 던지거나 처리할 것인지
- 파일의 확장자를 기반으로 어떤 파일인지 분류하고, 각 파일 종류를 TextReaderKind 열거형으로 나타냄
  - TextReaderKind는 static 메서드로 확장자를 받아 적절한 멤버를 반환함
  - TextReaderKind에서 멤버에 자신에게 해당하는 TextReader를 반환하는 메서드 구현
